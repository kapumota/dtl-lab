### Experimentos del Paper 1

#### Propósito

Este directorio almacenará configuraciones y scripts de experimentación del Paper 1.

La Fase 0 no agrega experimentos ejecutables. El directorio se crea para definir desde el inicio una separación clara entre código de producción, configuraciones experimentales y resultados.

#### Contenido previsto

- configuraciones de TLC;
- scopes y comandos de Alloy;
- catálogo de mutantes;
- escenarios Java deterministas;
- seeds de ejecución;
- scripts de conformidad;
- manifiestos de reproducción.

#### Reglas

- No almacenar resultados editados manualmente.
- No almacenar binarios de herramientas sin una justificación explícita.
- Cada experimento debe declarar versión de herramientas, commit y configuración.
- Los scripts deben fallar cuando falta una dependencia obligatoria.
- Los experimentos del futuro Paper 2 no deben mezclarse con este directorio sin una separación explícita.
