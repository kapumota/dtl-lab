\section{Conclusions}
\label{sec:conclusions}

This paper evaluated an executable cross-shard commit protocol through a reproducible multi-layer evidence workflow that combines bounded property verification, mutation-based property validation, bounded implementation-model trace conformance, verification-cost characterization, and independent reproduction of the analytical artifact. The contribution lies in integrating these evidence layers under one frozen experimental protocol rather than in claiming novelty for any individual verification technique.

For RQ1, the valid TLA+ and Alloy models produced no observed property violations among the completed bounded configurations. Of 420 measured RQ1 executions, 350 completed and 70 TLC-large executions were censored by timeout. This result therefore supports only the bounded conclusion that no counterexample was observed in the completed configurations; it does not constitute an unbounded proof of protocol correctness. For RQ2, all 10 predefined scientific mutants were detected, yielding a mutation score of 1.0 for the evaluated catalogue. This demonstrates sensitivity to the selected defect classes, not completeness with respect to arbitrary implementation or modelling faults.

For RQ3, the 600 evaluated executions supported the expected bounded implementation-model trace-conformance outcomes: the valid trace population was accepted and the deliberately corrupted population was rejected with the expected diagnostics. This connects selected observable Java executions to actions admitted by the formal abstraction, but it does not establish a general refinement relation or behavioral equivalence between the implementation and either formal model. For RQ4, the completed Alloy bound profiles showed increasing elapsed time and memory use, while all measured TLC-large executions reached the timeout threshold. These observations characterize the empirical verification envelope of the evaluated configurations; they do not establish a nonlinear or asymptotic scaling law and do not support absolute TLC-versus-Alloy performance claims.

The combined evidence should therefore be interpreted as complementary rather than cumulative proof. Bounded model checking constrains the property claims, mutation analysis tests sensitivity to predefined defects, trace conformance connects selected implementation behavior to the formal abstraction, and cost characterization defines the practical boundary under which that evidence was obtained. The frozen experimental protocol preserves the relationship among these layers and prevents post hoc changes to profiles, seeds, censoring rules, or statistical treatment.

The analytical artifact was independently exercised from a separate clone and workspace under a separate operating-system user on the same native Linux host. The successful reproduction completed 10/10 validation gates and matched 32/32 expected analysis-artifact hashes. This provides evidence of process separation and deterministic reconstruction of the preserved analytical outputs, but not hardware independence, a complete rerun of all 1,272 scheduled tasks, or scientific correctness from hash agreement alone.

Overall, the study shows that a cross-shard protocol can be evaluated through a single reproducible workflow that links bounded formal verification, controlled defect sensitivity, implementation-model trace evidence, and verification cost while keeping the limits of each evidence layer explicit. Further validation can extend the current bounds, broaden the scientific mutation catalogue and trace scenarios, and repeat the reproduction on an independent physical machine. These extensions would strengthen external validity without changing the bounded interpretation of the evidence reported in this paper.
